## Findings

_Fill this section before sign-off. One bullet per concern; cite the file:line touched and either the test that covers it or the residual risk._

- **Alternate-path auth / grant bypass (fixed in this range).** Before #2525, only REST `/store` checked relationship type; MCP `store`, `create_relationship(s)`, `restore_relationship`, `create_interpretation` and `/interpretations/create` did not. Covered by `tests/integration/relationship_write_capability_surfaces.test.ts` (REST over HTTP and MCP methods, LEASE refused / REFERS_TO allowed).
- **Proxy trust / local-dev widening.** Diff to `src/actions.ts` adds capability gating and 403 envelopes only. No new reads of `X-Forwarded-For`, `Host` or `remoteAddress`; no `LOCAL_DEV_USER_ID` references added. `security:lint`: 0 errors (136 pre-existing warnings, none in changed lines).
- **Unauth public route.** No routes added; `security:manifest:check` reports in sync (123 routes).
- **Guest-access widening.** None. A guest (unrecognized signer) is still left to access policy; revoked/suspended/unbound/invalid/pin-conflict signers now get the deny ceiling on edge writes (narrowing).
- **AAuth downgrade.** None. Fails closed when an endpoint type does not resolve for the owner.
