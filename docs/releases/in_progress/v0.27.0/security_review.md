## Findings

_Fill this section before sign-off. One bullet per concern; cite the file:line touched and either the test that covers it or the residual risk._

- **Alternate-path auth / AAuth downgrade.** `src/actions.ts` (REST middleware near line 4599, `/mcp` gate near 2172) now calls `matchConfiguredBearer`. A match on either slot takes the same branch as the primary (same dev principal, same grants). No new principal, no scope widening. Covered by `tests/integration/bearer_handover_slot.test.ts`.
- **Handover slot misuse.** The slot is bounded (max 7 days, absolute instant with offset), fails closed on a missing or malformed expiry, a malformed value, a value equal to the primary, or no primary, and is rejected at expiry or when unset. Comparison is constant time over SHA-256 digests and both slots are always compared. Covered by `tests/unit/bearer_slots.test.ts`.
- **Durable credential minting.** `src/services/oauth_key_gate.ts` accepts the primary only, so a retiring bearer cannot mint an OAuth connection that outlives its window.
- **Logging.** No log line or error carries a bearer value or digest. Client labels are stripped of control characters, capped at 120 characters, and the audit event is throttled per client with a bounded map (512 entries).
- **Proxy trust / local-dev widening.** No new reads of `X-Forwarded-For`, `Host` or `remoteAddress`; no new `LOCAL_DEV_USER_ID` references (lint warnings listed are pre-existing). The bearer-matched path still uses `ensureLocalDevUser` exactly as the primary did.
- **Unauth public route.** No new Express routes. `security:manifest:check`: in sync with `openapi.yaml` (126 routes).
- **Guest-access widening.** No change to `assertGuestWriteAllowed`, `routeAcceptsGuestPrincipal` or guest-token issuers.
- **Root landing.** `harness_snippets.ts`, `index.ts` and `site_nav.ts` changes are content and navigation; no change to `isLocalRequest` logic.
